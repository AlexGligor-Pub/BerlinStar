# Utilizatori

Colleagues' access accounts. Each one has a username, password and role.

> **Who has access:** only **Administrator** (from **Configurări → Utilizatori** or the **Utilizatori** tile in the menu).

## Add a user
1. Press **Adaugă utilizator**.
2. Fill in the name, username and role (**Administrator**, **Manager** or **Lucrător**).
3. Set a password (minimum 10 characters) or use the password generator.
4. Optionally, link the user to an **angajat** (employee) record.
5. At the end you can **Copia credențialele** (company code + username + password) to send them to the colleague.

## Password reset
From the row's **⋮** menu → reset the password. All active sessions of that user are immediately disconnected, so they must log in again with the new password.

## Deletion
From the **⋮** menu → **Șterge**, with a confirmation window. Deletion is "soft": the account becomes inactive, but the history remains. You cannot delete the company's last **Administrator**.

## Export
The export buttons produce the list of users in **CSV** or **PDF**, with the **company code** shown at the top.

> Existing passwords **cannot be shown in clear text** — they are stored encrypted, irreversibly. That's why, at creation time, you should note down or copy the password right away.
