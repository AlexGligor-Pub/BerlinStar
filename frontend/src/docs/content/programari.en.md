# Programări

The workshop's appointment calendar.

> **Who has access:** everyone. Canceling/deleting an appointment is a privileged action (**Administrator** / **Manager**).

## How you schedule
1. Choose the day from **Calendar** (or **Azi**).
2. Press for a new appointment and choose **Client** (or **Client nou**).
3. Set **Data**, **Ora start**, **Ora sfârșit** (or use **Durată rapidă**) and **Departament**.
4. Add **Notițe** if needed and save.

## Statuses
An appointment goes through: **Programat → Confirmat → In lucru → Executat**, or **Anulat**. Update the status so the day's planning reflects reality.
