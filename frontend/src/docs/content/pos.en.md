# POS — sale

The cash register: you open a ticket, add products and services, generate the estimate (deviz).

> **Who has access:** everyone (Administrator, Manager, Lucrător).

## Basic flow
1. Choose **Deviz Nou** or **Deschide existent** to resume a ticket.
2. Select **Departament** and, where applicable, **Angajați**, so the sale is attributed correctly.
3. Add items to the ticket: each **Linie** has the product/service, quantity and price.
4. Send the ticket to **Recepție** for payment, discounts and documents.

## Keep in mind
- **Simplu** mode hides the advanced details for a quick sale.
- Employee attribution matters: it feeds the employee's target and the reports.
- An open ticket stays saved; you can resume it any time from **Deschide existent**.
