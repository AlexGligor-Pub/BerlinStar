# Factură Rapidă

Számla kiállítása anélkül, hogy egy műhelyi Deviz-en keresztülmennél.

> **Cine are acces:** **Administrator** és **Manager** (haladó terület).

## Mikor használod
Egyszerű értékesítéshez vagy egy alkalmi szolgáltatáshoz, amikor nincs szükséged a POS/Recepție teljes lapjára.

## Folyamat
1. Válaszd ki vagy add hozzá az ügyfelet (a CUI alapján ANAF-ból történő átvétellel).
2. Add hozzá a számla sorait (megnevezés, mennyiség, ár, ÁFA).
3. Generáld le a dokumentumot; ez továbbküldhető az **e-Factura** felé.
