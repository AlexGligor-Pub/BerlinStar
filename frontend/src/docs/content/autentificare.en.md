# Authentication

Logging into the application for a company's colleagues.

> **Who has access:** anyone with an account in the company.

## How you log in
Login requires three things:

1. **Cod firmă** — identifies the company. It is the same for all colleagues.
2. **Utilizator** — your username (unique only within the company).
3. **Parola** — your personal password.

The company code used last time stays pre-filled on that station, so it doesn't have to be retyped for every shift.

## New company account
From the login screen, the registration button creates a new company together with the first **Administrator** account. To add colleagues to an existing company, see the **Utilizatori** section — do not register again.

## Conditions and limits
- After too many wrong attempts within a minute, authentication is temporarily blocked (anti-brute-force protection).
- An account with an expired trial period can be blocked until the subscription is activated.
- On **Logout** or a new login, the previous user's browser data is cleared; only the theme and the station's device stay.
- The administrator can remotely disconnect any active session. If you get disconnected suddenly, log in again.
